# 🏫Timetable-viewer
## 📕Introduction
It helps colleges and universities to view timetables conveniently with a good UI which is originally stored in excel format.</br>
Built as a university level project.</br>
**Team Members:** Aditi Balaji</br> Yaswanth Gudivada</br> Nallamalli Yashwanth Sriram

## 📕Features
1. Converts a normal excel sheet to a good UI to view timetables
2. Has separate admin access to maintain security and accessibility to upload the files
3. Easy filters to navigate better
